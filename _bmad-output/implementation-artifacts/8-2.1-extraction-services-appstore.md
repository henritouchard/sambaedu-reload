# Story 8.2.1 : Extraction des services depuis AppStoreService

Status: done

## Story

As a **développeur**,
I want découper le god-service `AppStoreService` en services spécialisés,
So que chaque domaine de responsabilité est isolé et que l'ajout du flow d'installation multi-fichiers ne complexifie pas un fichier monolithique.

## Contexte

`AppStoreService` (750 lignes) cumule : sync dépôt, installation, désinstallation, génération packages.xml, stats, consultation catalogue. Il doit être découpé en 4 services :

```
app/Services/AppStore/
├── DepotSyncService.php         # Sync catalogue distant → depot_applications
├── PackageInstallerService.php  # (squelette vide pour l'instant)
├── PackagesXmlService.php       # Génération/maintenance du packages.xml local
└── AppStoreService.php          # Orchestrateur : catalogue, stats, façade Livewire
```

**Contrainte** : refactoring pur, zéro changement de comportement. Les composants Livewire continuent d'injecter uniquement `AppStoreService`.

## Acceptance Criteria

1. **DepotSyncService créé** — Given `syncDepot()`, `syncAllDepots()`, `parseAndUpsertApplications()` sont extraits dans `DepotSyncService`, When je synchronise un dépôt depuis le tab Dépôt, Then le comportement est identique à avant.

2. **PackagesXmlService créé** — Given `updateLocalPackagesXml()` est extrait dans `PackagesXmlService::regenerate()`, When une application est installée ou désinstallée, Then le `packages.xml` est régénéré comme avant.

3. **PackageInstallerService squelette** — Given `PackageInstallerService` existe avec un squelette vide, When il est injecté dans `AppStoreService`, Then aucune erreur n'est levée (le flow d'installation actuel reste dans `AppStoreService` pour l'instant).

4. **AppStoreService délègue** — Given `AppStoreService` injecte les 3 sous-services, When les composants Livewire appellent `AppStoreService`, Then les appels sont délégués aux bons services.

5. **Aucune régression** — Given le refactoring est terminé, When je navigue dans les tabs Dépôt et Applications, Then tout fonctionne comme avant (sync, liste, filtres, stats, installation mono-fichier).
