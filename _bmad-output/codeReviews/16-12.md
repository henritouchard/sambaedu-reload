### F2 — 🟠 Wrapper Windows : base64 tronqué silencieusement pour scripts > ~6100 bytes

**Fichier** : `resources/views/auth/v1/wrapper-cmd.blade.php` ligne 34

**Constat sonnet** : `>"%B64_FILE%" echo {{ $script_content_b64 }}` — `cmd.exe` impose 8191 chars/ligne. PHP `base64_encode()` ne coupe pas, donc un script user de 6200 bytes → ~8267 chars b64 → **silencieusement tronqué** par cmd.exe. `certutil -decode` produit un .cmd corrompu → script user non exécuté sans signature claire.

**Avis Opus (pertinence 3/3 — confirmé)** : Vérifié ligne 34. Pire que ce que dit sonnet : le wrapper postera quand même `STATUS=failure` mais **sans signature claire "script tronqué"** → debugging difficile. Risque réel en prod : un script logon administrateur typique fait facilement 5-10 KB.

**Solutions** :
1. Splitter le b64 en chunks de 4000 chars avec `>> "%B64_FILE%" echo <chunk>` multiple (simple, conserve cmd-only)
2. PowerShell `Set-Content -Path $env:B64_FILE -Value '<chunk>'` (plus robuste, mais requiert PowerShell embedded escape)
3. PowerShell here-string `[IO.File]::WriteAllText` (compact)

**Action** : ⏳ Décision Henri Q2 — taille typique scripts dans le parc + choix de solution.

### F4 — 🟡 Wrapper Windows : truncation chars Unicode pas bytes UTF-8

**Fichier** : `resources/views/auth/v1/wrapper-cmd.blade.php` ligne ~70-71

**Constat sonnet** : `GetByteCount` pour vérifier mais `Substring(0, 4000)` pour tronquer (UTF-16 chars). Pour CJK/emoji 3-4 bytes UTF-8, 4000 chars peuvent dépasser 8192 bytes UTF-8.

**Avis Opus (pertinence 2/3)** : Le payload max est 16 KB côté FormRequest (`'stdout' => max:16384`), puis mutator modèle `mb_strcut` re-tronque à 8192. **Pas de bug fonctionnel** — juste comportement non documenté en D4. La doc D4 dit "truncate à 4 KB head + 4 KB tail" mais le wrapper fait du 4000 chars (donc jusqu'à 12 KB UTF-8 dans le pire cas).

**Solution** : Ajuster la D4 dans la story pour préciser "4000 chars Unicode head + 4000 chars Unicode tail, re-tronqués serveur-side à 8 KB UTF-8". Ou (plus invasif) corriger le PowerShell pour tronquer en bytes UTF-8 réels.

**Action** : 🔧 Auto-corrigible — ajustement story (~5 lignes D4).

### Opus-A — 🟠 Replay JWT non bloqué sur l'endpoint d'ingestion
