## Détail des problèmes

### #1 — Drift du vhost fallback config/apache/sambaedu.conf

**Sévérité** : 🟠
**Fichier(s)** : `config/apache/sambaedu.conf`, `tests/Architecture/IpxeStaticAliasTest.php`

**Constat (review sonnet)** : le template fallback (utilisé par `update.sh` quand `setupApache.sh` est absent/non exécutable — chemin réel, pas mort) référençait encore `Alias /ipxe /var/www/sambaedu/ipxe`, en contradiction directe avec l'objectif de la story ; aucun test ne couvrait ce fichier.

**Évaluation orchestrateur** : Pertinence 3 — vérifié : `update.sh:22` (`APACHE_CONF_SOURCE`) et `:437-440` utilisent bien ce fichier ; son header exige « garder les deux en phase ».

**Action** : corrigé automatiquement — alias repointé sur `/var/www/sambaedu-reload/storage/ipxe/static` (+ garde-fou sécurité), nouveau test `apache_conf_fallback_template_stays_in_phase` qui verrouille l'absence de référence legacy + FallbackResource.

### #2 — Publication sans miroir (orphelins servis indéfiniment)

**Sévérité** : 🟡 — **Évaluation** : Pertinence 2 (robustesse objective, solution claire).
**Action** : corrigé — purge fichier-par-fichier des orphelins de `storage/ipxe/static/` absents de `resources/ipxe/static/` (pas de rm -rf, pas de dépendance rsync), puis rmdir des dossiers vides.

### #3 — Traversée du parent storage/ipxe/ non garantie

**Sévérité** : 🟡 — **Évaluation** : Pertinence 2 (404 silencieux plausible sous umask durci).
**Action** : corrigé — `chmod u+rwX,go+rX` explicite sur `storage/ipxe/` en plus du `-R` sur `static/`.

### #4 — Trou de preuve AC7 (noop: avec legacy_path null)

**Sévérité** : 🟡 — **Évaluation** : Pertinence 2.
**Action** : corrigé — test `test_blocked_script_route_noop_still_works_with_missing_legacy_path` ajouté.

### #5 — Commentaire garde-fou manquant sur le bloc /ipxe

**Sévérité** : 🟡 — **Évaluation** : Pertinence 2 (cohérence avec les blocs voisins, coût nul).
**Action** : corrigé — commentaire « GARDE-FOU SÉCURITÉ » ajouté dans setupApache.sh (et dans le template fallback).
