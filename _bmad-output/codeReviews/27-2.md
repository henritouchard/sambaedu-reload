## Détail des problèmes

### #2 — Défaut imprimante non retiré quand l'admin décoche (🟠, pertinence Opus 3)

**Fichier(s)** : `agent/shared/handler_printers.go` (`Apply` ~l.241, `Test` ~l.164)

**Constat (review sonnet)** : `Apply` n'entre dans le bloc « poser le défaut » que `if defaultConn != ""`.
Quand l'admin décoche le défaut sur tous les WG, le payload n'a plus aucun `is_default:true` → `defaultConn ==
""` → l'ancien défaut Windows reste. `Test` (l.164) ne compte aucune dérive non plus. Le test
`TestPrintersDefaultFollowsRuleChange` ne prouve que le **déplacement** imp1→imp2, jamais le **retrait**.

**Avis Opus (3/3)** : confirmé, c'est le vrai trou de level-triggered de la story. **Nuance** : ce n'est pas un
fix mécanique — Windows impose toujours UNE imprimante par défaut, « décocher » n'a pas de cible naturelle. Le
comportement actuel (laisser tel quel) est défendable mais **non documenté ni testé**. **M1** est l'angle
reporting jumeau : le poste rapporte `compliant` alors que Windows garde l'ancien défaut (le poste « ment »).

**Action** : **décision Henri requise** (Q1). Une fois la sémantique tranchée → test + ligne de doc figeant le
choix, sur `Apply` ET `Test`.

### #1 — `Blocked()` printers toujours `false` (🟠, pertinence Opus 1)

**Fichier(s)** : `agent/windows/handler_printers_windows.go` (~l.137)

**Constat (review sonnet)** : `Blocked()` retourne `false` en dur → `ListManaged()` pourrait désinstaller une
connexion `\\<se4fs>\…` ajoutée manuellement par l'utilisateur.

**Avis Opus (1/3)** : raisonnement de sonnet **partiellement faux**. `ListManaged()` filtre par préfixe
`\\<serveur SambaEdu>\` → ne peut JAMAIS retourner une connexion vers un autre serveur. Le scénario réel se
limite à une connexion **vers le serveur SambaEdu** — cohérent avec « le serveur SambaEdu fait foi ». Choix de
design défendable et déjà esquissé en Dev Notes.

**Action** : **décision Henri** (Q2) — confirmer la règle « connexion vers serveur SambaEdu = périmètre
SambaEdu ». Documentation au schéma suffit, aucun code à changer par défaut.

### #3 — `stableSourceId` collision crc32 → ordre/ETag non déterministe (🟡, pertinence Opus 2) — CORRIGÉ

**Fichier(s)** : `app/Services/Agent/Providers/PrintersStateProvider.php` (~l.256)

**Constat** : `group_id*1e9 + (crc32(cups_name) % 1e9)` ; deux `cups_name` distincts du même groupe peuvent
collisionner → `usort` non stable en PHP → **hash d'agrégat instable** (churn d'ETag, re-téléchargement inutile).

**Avis Opus (2/3)** : réel, vecteur = déterminisme de l'ordre (pas la dédup). Probabilité faible, impact = churn
ETag (pas de corruption). **Fix sûr** : tiebreak déterministe sur `cups_name`.

**Action** : **corrigé automatiquement** — tiebreak `cups_name` ajouté à l'ordre des candidats.

### #6 — Toggle défaut sans `@can('manage-printer')` → 403 au clic (🟡, pertinence Opus 3) — CORRIGÉ

**Fichier(s)** : `resources/views/pages/parc/groups/[id]/_partials/printers-list.blade.php` (~l.60-66)

**Constat** : le toggle « Par défaut » est rendu sans garde. La page est accessible à un **délégué scopé**
(`Gate::allows('view', $group)`), mais `toggleDefaultPrinter` exige `manage-printer` (= `server.admin` global,
non scopable) → le délégué voit un toggle cliquable qui lève systématiquement un 403.

**Avis Opus (3/3)** : confirmé. Guard serveur correct, mais l'affordance UI ment. Pattern correct déjà présent
dans le même fichier (`@can('wallpaper.manage')`).

**Action** : **corrigé automatiquement** — `<td>` toggle enveloppé dans `@can('manage-printer') … @else <td>—</td> @endcan`.

### #5 — `letterForIndex` plafonne à `Z:` sans log (🟡, pertinence Opus 1) — CORRIGÉ

**Fichier(s)** : `app/Services/Agent/Providers/DrivesStateProvider.php` (~l.160-168)

**Constat** : `break` silencieux au-delà de 16 classes ; pas de log → classes droppées invisibles.

**Action** : **corrigé automatiquement** — `Log::warning` quand des classes sont droppées faute de lettres.

### #4 et #7 — Hors-scope (préexistants)

- **#4** : `report.v1.json` placeholder hash sur item `error` — **inchangé par 27.2**, item error non
  recompute-vérifié, sans impact. Pas d'action.
- **#7** : `description/location/uri` non hydratés sur `Printer` (vivent dans CUPS) — **dette préexistante**
  rendue avant 27.2, pas embarquée ici.

### M3 — Invariant non protégé (🟡) — DOCUMENTÉ

L'unicité du défaut + la dédup ne tiennent QUE parce que `is_default` est résolu **globalement** dans le
provider (jamais porté par le pivot brut au payload). Si un futur refactor faisait porter `is_default` par le
pivot brut, deux candidats de la même imprimante divergeraient (`true` vs `false`) → non dédupliqués → imprimante
en double. **Action** : ligne de garde ajoutée dans `docs/agent/state-providers.md`.
