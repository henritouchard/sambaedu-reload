## Détail des problèmes

### #1 — Régression scope `list` / `list_m`

**Sévérité** : 🟠 Important
**Fichier(s)** : `app/Dto/AppCustomization/AppContext.php:47-83`, `app/Services/AppCustomization/AppCustomizationService.php:80-103`, `app/Http/Controllers/AppPolicyController.php:81-99`

**Constat initial (Sonnet)** :
Le legacy `ff_import_policy` utilise `$info['list']` = union `list_u` + `list_m` (CN machine + salle + parcs AD). Le nouveau code ne prend que `list_u` (AppContext.php:50-52) et résout uniquement `salleName`. Overrides par machine CN ou parcs AD hors salle perdus.

**Avis Opus** : Pertinence 2. Vraie régression **partielle** atténuée par le fait que **le spec lui-même** omet `list_m` dans l'AC4. C'est autant un gap de spec que d'implémentation. Impact réel dépend de l'usage prod — si aucun étab n'a de `<machine_cn>.json` / `<parc_ad>.json` legacy, régression invisible.

**Solutions possibles** :
1. Étendre `AppContext` avec `groupsMachine: string[]` + ajouter niveau 3bis dans `resolvePoliciesForMachine` itérant sur `list_m`
2. Documenter explicitement comme breaking change assumé ("les overrides CN machine / parcs AD hors salle ne sont plus supportés — migrer en WorkstationGroup explicite") — plus propre sémantiquement
3. Hybride : implémenter (1) pour compat ; flagger en config `app_customizations.fallback_list_m_scopes` désactivable

**Action** : en attente Q1 — inventaire prod requis

### #3 — `throttle:60,1` casse déploiements grande échelle

**Sévérité** : 🟠 Important
**Fichier(s)** : `routes/web.php:268-286`

**Constat initial (Sonnet)** :
60 req/min/IP — 300 postes derrière NAT simultanés → 429. Legacy sans rate limit.

**Avis Opus** : Pertinence 2. **Vrai bug opérationnel édulcoré**. SE4FS intranet : postes ont généralement IPs distinctes, pas un seul NAT. Spec AC11 demande explicitement throttle:60,1 — mais 60/min trop agressif en pratique (admin qui teste = triple déclenchement).

**Solutions possibles** :
1. Passer à `throttle:300,1` (5/s/IP) — défense anti-scan sans blocage opérationnel
2. Limiter par `$id` (APCu session id) via `RateLimiter::for()` nommé — plus précis
3. Rate limiter conditionnel dev/prod via config

**Action** : en attente Q2 — défaut pragmatique `throttle:300,1` suggéré

### #4 — Arbitrary class instantiation via `$scopeType`

**Sévérité** : 🟠 Important
**Fichier(s)** : `resources/views/livewire/firefox-customize-form.blade.php:207-208`, `resources/views/livewire/thunderbird-customize-form.blade.php:113-114`, `resources/views/components/molecules/app-customization-card.blade.php:96-100`

**Constat initial (Sonnet)** :
`$scopeType` public Livewire → un admin avec `app.customize` peut forger `scopeType = "App\Models\X"` arbitraire, `::query()->find($scopeId)` → lecture/pollution morphTo hors contexte.

**Avis Opus** : Pertinence 2. Titre "path traversal" **incorrect** — c'est **arbitrary class instantiation + IDOR**. Atténué par gate `app.customize` (admin trusted). Pattern 4-7 wallpaper-card a la même vulnérabilité préexistante (à tracker séparément).

**Solutions possibles** :
1. Constante `ALLOWED_SCOPE_TYPES` dans chaque component + validation dans `resolveScope()`
2. Remplacer `$scopeType` par un enum `ScopeKind` exposant `toClass()` serveur-side
3. Utiliser `Relation::morphMap()` global + stocker des alias courts

**Action** : ✅ Corrigé automatiquement (solution 1 — allowlist explicite, pragmatique)

### #10 — Body `{}` vs `""` sur id vide

**Sévérité** : 🟠 Important
**Fichier(s)** : `app/Http/Controllers/AppPolicyController.php` (endpoints legacy)

**Constat initial (Sonnet)** :
`response()->json(new \stdClass(), 200)` → body `{}` (2 bytes). Legacy fait `exit()` → body vide (0 bytes). Scripts bash `[ -s /tmp/result ]` cassés.

**Avis Opus** : Pertinence 2. Vraie différence comportementale. Spec dit explicitement "réponse vide HTTP 200 (fidèle au `exit()` legacy)".

**Solutions possibles** :
1. Remplacer `->json(new \stdClass(), 200)` par `response('', 200, headers)` — vrai body vide
2. Ajouter assertion `assertContent('')` dans test `firefox_out_empty_id_returns_empty_200`

**Action** : ✅ Corrigé automatiquement
