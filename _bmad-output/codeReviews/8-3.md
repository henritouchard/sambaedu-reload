## Détail des problèmes

### #1 — Injection shell → RCE root via `extra_option`

**Sévérité** : 🔴 Critique · **Pertinence Opus : 3/3 (exploitabilité root confirmée par traçage complet de la chaîne)**
**Fichier(s)** : `app/Services/Network/DhcpSubnetService.php:validateExtraOption`

**Constat initial (review Sonnet)** :
`validateExtraOption` n'interdisait que l'espace (`\s`) et le guillemet double, **pas l'apostrophe simple**. La valeur est rendue telle quelle dans `dhcp-subnets.conf` (`dhcp_extra_option_N = "<val>"`), fichier sourcé sur la VM par `config.inc.sh::get_config()` qui réinjecte la valeur **entre apostrophes simples** avant un `eval` — exécuté en **root** (`make_dhcpd_conf.sh` lancé en sudo par `DhcpService::reloadService()`).

**Avis Opus (vérification indépendante)** :
Chaîne tracée jusqu'au `eval` réel de `config.inc.sh` (`s|^(\S+)\s*=\s*"(.*)"$|config_\1='\2'|` puis `eval $ligne`). Le glob `find …/sambaedu.conf* -name "*.conf"` descend bien dans `sambaedu.conf.d/` → `dhcp-subnets.conf` est sourcé. Payload confirmé **sans aucun espace ni guillemet double** :
```
/a';{touch,/tmp/pwned};x='
```
→ `config_dhcp_extra_option_20='/a';{touch,/tmp/pwned};x=''` → brace expansion (`{touch,/tmp/pwned}`, insensible à `IFS`) → `touch /tmp/pwned` **exécuté en root**. Escalade admin-app (`manage-dhcp`/`server.admin`) → RCE root persistante. Champ atteignable depuis l'UI (`index.blade.php` input `wire:model="extra_option"`). `escapeshellarg` inopérant (ce n'est pas un argument shell mais une valeur INI `eval`-uée par un autre parseur) → whitelist = seule protection correcte.

**Correction appliquée** :
Liste blanche stricte `#^/[A-Za-z0-9._/-]+$#` (chemin absolu, rejette `'` `"` `;` `` ` `` `$` `{}` `|` `&` espaces). Commentaire de sécurité détaillé dans le code.

**Action** : ✅ Corrigé automatiquement.

### #3 — TOCTOU : validation de chevauchement / `vlan_id` hors section critique

**Sévérité** : 🟠 Important · **Pertinence Opus : 2/3 (vrai trou, faible probabilité)**
**Fichier(s)** : `app/Services/Network/DhcpSubnetService.php` (createSubnet/updateSubnet/deleteSubnet)

**Constat initial + vérification Opus** :
Le lock `dhcp.reload` était acquis **après** le commit SQL (dans `reloadAfterMutation`). `assertNoSubnetOverlap` (SELECT) et l'INSERT/UPDATE étaient hors section critique. Seul `vlan_id` est `UNIQUE` en base (aucune contrainte sur `network`). Deux créations concurrentes de VLAN de n°s différents mais **réseaux chevauchants** pouvaient toutes deux passer la validation → `dhcpd.conf` avec deux `subnet{}` recouvrants (reload dhcpd en échec). **S2 (cousin)** : deux créations du même `vlan_id` en parallèle → `QueryException` brute (toast 500) au lieu du message « VLAN déjà défini ».

**Correction appliquée** :
Refactor `reloadAfterMutation` → `withReloadLock(action, mutate, ctx)` : le lock est acquis **avant** `normalizeAndValidate` + écriture SQL + export + reload. La validation et l'écriture sont désormais dans la même section critique (ferme le TOCTOU inter-VLAN + la course `vlan_id`). Mode dégradé AC5 préservé (commit + export conservés si le reload échoue ; `DhcpCommandException` propagée). MÊME clé de lock que la 8.1 → sérialise aussi vis-à-vis des réservations.

**Note** : le TOCTOU inter-service (réservation créée en parallèle tombant dans une plage en création) reste borné côté 8.1 (la validation des réservations de `DhcpService` est aussi hors lock) — hors scope 8.3, non aggravé.

**Action** : ✅ Corrigé automatiquement.

### #2 — `ensure_dhcp_scripts` non idempotent sur le bit exécutable

**Sévérité** : 🟠 Important · **Pertinence Opus : 2/3 (réel, faible probabilité, fix trivial)**
**Fichier(s)** : `scripts/update.sh:ensure_dhcp_scripts`

**Constat** : le skip reposait sur `cmp -s` (contenu seul). Un `dst` au bon contenu mais mode ≠ 755 (chmod/cp accidentel, restauration) n'était jamais redéployé → `sudo make_dhcpd_conf.sh` échoue en EACCES, à l'opposé d'AC6 « idempotent, exécutable ».

**Correction appliquée** : ajout de `[[ -x "$dst" ]]` à la condition de skip → redéploie via `install -m 755` si le bit x manque.

**Action** : ✅ Corrigé automatiquement.
