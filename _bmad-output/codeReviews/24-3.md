## Détail des problèmes

### #1 — Login vide / comptes virtuels dans l'énumération des sessions

**Sévérité** : 🔴
**Fichier(s)** : `agent/windows/SambaEduAgent.ps1` (Get-InteractiveSessions)

**Constat initial (review)** : le filtre excluait les SID nuls et DWM/UMFD (`^S-1-5-9[06]-`) mais ne validait pas que `Win32_Account.Name` est non vide ; les comptes virtuels (`S-1-5-80-*`, `S-1-5-82-*`) passaient. Conséquence en parc : caches `cache\sessions\<SID-service>\` parasites et fetchs `GET /state?user=` (vide) indistinguables d'un vrai login.

**Avis Fable** : pertinence 3 — corrigé.

**Action** : corrigé automatiquement — liste blanche `$sid -match '^S-1-5-21-'` (users réels domaine/local) + garde `[string]::IsNullOrWhiteSpace($account.Name)`. Pendant serveur figé par le test #9. Entrée Post-correctifs ajoutée au runbook QA (vérifier au lab qu'aucun répertoire `cache\sessions\` hors `S-1-5-21-*`).

### #3 — TOCTOU sur `.tmp` à nom fixe (cache per-SID, puis token)

**Sévérité** : 🟠
**Fichier(s)** : `agent/windows/SambaEduAgent.ps1` (Save-SessionStateCache, Save-AgentToken)

**Constat initial (review)** : 24.3 introduit un second écrivain SYSTEM (tâche at-logon) concurrent du cycle service sur le même `state.json.tmp` → contenu corrompu ou `Move-Item` en échec possible. 24.2 n'avait qu'un écrivain.

**Avis Fable** : pertinence 3 — corrigé, et étendu : `Save-AgentToken` avait le même défaut, plus grave (rotation D5 reçue par les deux acteurs → token corrompu = 401 irrécupérable en chaîne).

**Action** : corrigé automatiquement — tmp suffixé `$PID` pour le cache session ET le token ; cache machine mono-écrivain intouché.

### #9 — Test serveur `?user=` vide

**Sévérité** : 🟡
**Fichier(s)** : `tests/Feature/Api/V1/Agent/SessionCompanionE2eTest.php`

**Constat initial (review)** : aucun test ne figeait que `?user=` (paramètre présent mais vide) → machine-only propre, sans log `unknown_user` — précisément le cas que #1 pouvait générer.

**Avis Fable** : pertinence 3 — corrigé.

**Action** : test `empty_user_param_yields_the_machine_context_without_unknown_user_noise` ajouté (200, ETag machine identique, zéro `unknown_user`, 304 machine à travers `?user=` vide). Tests VM : **189 passed (745 assertions)**, zéro régression.
