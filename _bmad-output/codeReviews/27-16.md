## Détail des problèmes

### #1 — 🔴 `import_gpo` lie automatiquement la GPO à la RACINE du domaine

**Fichier(s)** : `app/Services/Gpo/AgentBootstrapPublisher.php` (appel `import_gpo`) → `../sambaedu/includes/gpo.inc.php:1035-1052`

**Constat (vérifié)** : après `sysvol_put`, `import_gpo` exécute `if (empty($info['links'])) { $info['links']['rdns'][0] = $config['ldap_base_dn']; }` puis `gposetlink(...)`. Le `GPT.INI` de `SE_agent_bootstrap` ne contient que `[General]`+`[CSE]`, **aucune `[links]`** → la GPO est liée à la **racine** au premier publish (dedup idempotent ensuite via `gpolistcontainers`, mais le lien racine existe). C'est exactement le scénario interdit par AC3 : agent SE5 poussé sur les 75 collèges. La recon DEV a vu que `import_gpo` *crée* la GPO mais a manqué qu'il la *lie* aussi.

**Action** : **Corrigé auto** (option b du reviewer, la plus sûre) — après `import_gpo`, appeler `GpoService::removeLink($baseDn, ...)` de façon **inconditionnelle et idempotente** pour neutraliser tout lien racine, AVANT le `setLink` sur l'OU établissement. Test ajouté asseyant qu'aucun lien racine ne subsiste. Validation terrain Q1.

### #2 — 🟠 Hôte SYSVOL divergent publication vs vérification
**Fichier** : `AgentBootstrapPublisher.php` (`dcHost()`/vérif) vs legacy `sysvol_put` (`ad_url($config,'dns')` = `se4ad_name`)
**Constat** : la vérif lit `//getHosts()[0]/sysvol` (peut être une IP → échec SASL/canonicalisation, cf. `project_ipxe_boot500_sasl_nocanon`) alors que l'écriture passe par le FQDN `se4ad_name`. Faux échec possible (écriture OK, vérif KO → `failed`).
**Action** : **Corrigé** — vérif alignée sur `se4ad_name`/`ad_url dns`. Validation Q3.

### #3 — 🟠 `kinit --password-file=/dev/stdin` non garanti
**Fichier** : `AgentBootstrapPublisher.php` (kinit)
**Constat** : flag non universel (MIT vs Heimdal) ; si ignoré → kinit lit le TTY → blocage/échec. Le commentaire du code lui-même hésite.
**Action** : **Durci** — écriture du mot de passe dans un fichier temp `0600` (ccache-adjacent, purgé en `finally`) + `--password-file=<fichier>` ; timeout Process. Binaire à valider Q2.

### #4 — 🟠 Vérif d'écriture aveugle au faux-succès en re-run
**Fichier** : `AgentBootstrapPublisher.php` (verifyRealWrite)
**Constat** : ne vérifie que `taille>0` ; en re-run le fichier préexiste → un échec d'écriture courant passe inaperçu. `import_gpo` peut aussi `return true` sans `sysvol_put` (version non incrémentée).
**Action** : **Corrigé** — compare la **taille exacte attendue** du `startup.cmd` spécialisé (calculable après substitution) ; à défaut documente « présence » vs « écriture de ce run ». En `--force`, exige le bump de version.
