### #S1 — Branche legacy `ShortcutCompilerService` / `ShortcutObserver` encore active

**Sévérité** : 🟠 — trouvé par Opus (manqué par sonnet)
**Fichier(s)** : `app/Services/ShortcutCompilerService.php:419` (+ `ShortcutObserver` enregistré `AppServiceProvider:207`, `CompiledShortcut`, `CompileShortcutsCommand`)

**Constat (opus)** : `ShortcutObserver` est actif ; à chaque CREATE/UPDATE de raccourci, `compile()` → `buildScriptFragment()` régénère un `script_fragment` contenant `http://{server}/api/v1/shortcuts/export` (route **supprimée** par 27.14) et le persiste (`CompiledShortcut`). Le canal **agent** ne consomme pas ce fragment (`ShortcutsStateProvider` émet `{icon, icon_asset, icon_checksum}` via `resolveForMachine`, indépendant de `buildScriptFragment`). C'est de la **glue legacy survivante orpheline** qui tourne et écrit une URL 404 — précisément ce que la story prétend éteindre (écart AC3). Non-bloquant runtime.

**Solutions possibles** :
1. **Amputer maintenant** : retirer `compile`/`buildScriptFragment`/`build*Fragment` de `ShortcutCompilerService` (garder `resolveForMachine`/`generateWindowsLnk` consommés par l'agent), désenregistrer `ShortcutObserver`, supprimer `CompiledShortcut` + `CompileShortcutsCommand` (et leur migration de table). Cohérent « un seul système ».
2. **Spin-off** : story de suivi dédiée (garde le diff 27.14 borné).
3. **Documenter** la conservation morte (peu défendable vu le KPI).

**Action** : ✅ **Corrigé — amputation + suppression intégrale** (décision Henri). Retirés de `ShortcutCompilerService` : toute la branche `compile*`/`build*Fragment`/`buildScript`/`getScriptHeader`, **et** `resolveForMachine`/`getUserAdGroups` (révélés morts — `resolveForMachine` dépendait des builders supprimés et ne servait que l'endpoint export mort, zéro consommateur vivant). Le service devenant alors 100 % code mort (grep : seules références = commentaires + binding), Henri a confirmé la **suppression intégrale** : `git rm` de `ShortcutCompilerService.php` + `WindowsLnkGenerator.php` (consommé uniquement par lui) + retrait du `singleton`/`use` dans `AppServiceProvider`. `ShortcutObserver` désenregistré + supprimé ; `CompileShortcutsCommand` supprimée ; modèle `CompiledShortcut` supprimé + relation morte `Shortcut::compiledShortcuts()`/`invalidateCompilation()` retirées (colonnes `compiled_*` laissées **dormantes** — réversible, pas de migration de drop). Commentaires obsolètes nettoyés (`ShortcutsStateProvider`, `WorkstationEnvironmentResolver`). Vérifié : `php artisan about` OK, `--filter Shortcut` 69 passed, `ShortcutsStateProvider`+`ContractV1` 19 passed, bootstrap vert.
