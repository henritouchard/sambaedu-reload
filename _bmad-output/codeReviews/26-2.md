## Questions en attente

> Nécessitent une réponse d'Henri avant clôture.

1. **Loopback Merge vs Replace (problème #2)** : trancher la reco par défaut de ciblage des postes nomades. `Replace` est le plus prédictible (seules les GPO ordinateur s'appliquent) mais **casse les autres GPO User légitimes** du poste (wallpaper, Firefox…). `Merge` additionne mais risque la collision avec la GPO `redirections` legacy. Décision de déploiement → quel défaut documenter ?
2. **GUID CSE Folder Redirection (problème #1)** : la paire `[{25537BA6-…}{88E729D6-BDC1-11D1-BD2A-00C04FB9603F}]` est une constante Windows bien établie (corrigée dans le runbook). Veux-tu la **confirmer sur le DC de lab** (`ldbsearch … gPCUserExtensionNames` sur une GPO FR créée via GPMC) avant tout déploiement par fichiers bruts ?
3. **HOME peuplé + exclusive rights / move (M2/M3)** : le smoke lab ne teste que le cas HOME vierge. La consigne `Grant exclusive rights` + `Move contents` sur un HOME **déjà peuplé** (cas normal SambaEdu) est un piège FR classique. À **valider en lab sur un HOME réel** avant de figer la consigne — OK pour reporter cette validation au smoke lab (note ajoutée) ?
