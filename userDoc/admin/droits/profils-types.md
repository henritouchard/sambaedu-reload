# Les profils types

SE5 est livré avec **neuf profils de droits** prêts à l'emploi, qui couvrent
les rôles courants d'un établissement. Cette fiche décrit ce que chacun
autorise, pour vous aider à choisir le bon avant de l'attribuer.

## Où ça se passe

Menu **Pilotage**, entrée **Gestion des droits**, onglet **Profils**. La liste
distingue les profils **initiaux** (repère « initial ») des profils
**personnalisés**.

## Les neuf profils initiaux

| Profil | Ce qu'il autorise |
| --- | --- |
| **Élève** | Aucun droit d'administration. |
| **Professeur** | Consulter les utilisateurs et réinitialiser leurs mots de passe — **seulement pour les élèves de ses classes**. |
| **Admin élèves** | Consulter et modifier les utilisateurs, réinitialiser leurs mots de passe — **seulement pour les élèves de ses classes**. |
| **Admin partages** | Gérer les partages de classe et les lecteurs réseau de l'établissement. |
| **Admin utilisateurs** | Gérer l'ensemble des comptes de l'établissement, y compris **attribuer et déléguer des droits** ; gérer les partages de classe et les lecteurs réseau. |
| **Technicien** | Voir les postes du parc, en prendre le contrôle à distance et leur affecter des applications. |
| **Référent numérique** | Réinitialiser les mots de passe, consulter les comptes ; voir les postes, installer un poste neuf ; gérer les lecteurs réseau et les règles d'accès aux dossiers. |
| **Admin machines** | Gérer l'ensemble du parc et des applications, personnaliser les applications des postes, gérer les règles d'accès aux dossiers. |
| **Super administrateur** | Tous les droits d'administration de l'établissement. |

::: attention
Les neuf profils initiaux sont **verrouillés** : on ne peut ni les renommer, ni
changer leurs droits, ni les supprimer. Ils portent un cadenas sur l'onglet
**Profils**, et leur fiche s'ouvre en lecture seule. Quand aucun d'eux ne
correspond exactement au besoin, composez un profil sur mesure plutôt que de
chercher à en modifier un.
:::

## Portée de classe et portée établissement

Les profils **Professeur** et **Admin élèves** n'exercent leurs droits que sur
les personnes de leurs **propres classes**. Les profils **Admin utilisateurs**,
**Référent numérique** et **Super administrateur** agissent, eux, sur **tout
l'établissement**. Cette distinction est expliquée dans
[Comprendre le modèle de droits](/admin/droits/comprendre-le-modele-de-droits).

## Quand aucun profil type ne convient

Si le rôle d'une personne ne rentre dans aucun de ces neuf profils, vous pouvez
en composer un sur mesure avec exactement les droits voulus : voir
[Composer un profil de droits](/admin/droits/composer-un-profil).
