# Réinitialiser un mot de passe

Cette fiche explique comment attribuer un nouveau mot de passe provisoire à un
compte qui a perdu le sien, ou à plusieurs comptes d'un coup.

*Aussi appelé : mot de passe oublié.*

## Où ça se passe

Menu **Pilotage**, entrée **Utilisateurs**. La réinitialisation s'ouvre par
**trois portes** selon le nombre de comptes visés :

- **un seul compte** : sur sa fiche, l'action **Réinitialiser le mot de passe** ;
- **plusieurs comptes** : cochez-les dans la liste, puis
  **Réinitialiser les mots de passe** dans la barre d'actions qui apparaît en
  bas ;
- **un groupe entier** : sur la fiche du groupe, l'action
  **Réinitialiser les mdp du groupe** (elle ne touche que les membres directs
  du groupe), ou une sélection de groupes dans l'onglet **Groupes**.

![Fenêtre de réinitialisation d'un mot de passe, avec le mot de passe provisoire masqué et les boutons Révéler et Copier (repère 1), et le choix d'export PDF ou CSV pour plusieurs comptes (repère 2).](/captures/admin/utilisateurs/reinitialiser-un-mot-de-passe/fenetre-reinitialisation.png)

::: droit-requis
Il faut détenir le droit de réinitialisation des mots de passe. Un enseignant
qui le détient ne l'exerce que sur les élèves de ses propres classes.
:::

## Les gestes

1. Ouvrez l'une des trois portes ci-dessus selon le nombre de comptes.
2. Confirmez la réinitialisation dans la fenêtre qui s'ouvre.
3. Récupérez le ou les mots de passe provisoires :
   - pour **un seul compte**, le mot de passe s'affiche à l'écran, masqué par
     défaut (**Révéler**, **Copier**) ;
   - pour **plusieurs comptes ou un groupe**, l'affichage à l'écran n'est pas
     proposé : vous **exportez** la liste au format **PDF** ou **CSV**. Le lien
     de téléchargement reste valable **20 minutes**.

::: delai-effet immediat
Dès l'action confirmée, l'ancien mot de passe ne fonctionne plus : c'est le
mot de passe provisoire qui vaut désormais.
:::

## Résultat observable

Le compte reçoit un **mot de passe provisoire**. À sa prochaine connexion, son
titulaire devra choisir lui-même un nouveau mot de passe pour le remplacer
(voir [On me demande de changer mon mot de passe](/poste/mon-compte/changement-impose)).

::: attention
Le mot de passe provisoire n'est **jamais conservé** par le serveur : il ne
pourra pas être ré-affiché plus tard. Exportez-le ou notez-le **immédiatement**,
et le lien d'export expire au bout de 20 minutes.
:::
