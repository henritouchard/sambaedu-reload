# Pourquoi telle application est-elle là (ou pas) sur mon poste ?

Cette fiche explique d'où viennent les applications que vous trouvez sur votre
poste, pourquoi elles peuvent changer, et comment demander une application qui
vous manque.

## Ce qui décide des applications de votre poste

Vous ne choisissez pas vous-même les applications de votre poste : c'est
l'établissement qui les décide. Votre poste fait partie d'un ensemble — sa
salle, son [parc](/glossaire#parc) — et il reçoit les applications retenues
pour cet ensemble. À cela s'ajoute un [socle commun](/glossaire#socle-commun) :
un jeu d'applications présent sur tous les postes de l'établissement.

Deux conséquences normales :

- deux postes de salles différentes peuvent porter des applications
  différentes — ce n'est pas une erreur, chaque salle a ses besoins ;
- une application peut aussi **disparaître** d'un poste, quand l'établissement
  décide de la retirer. Là encore, ce n'est pas une panne.

## Où je vois mes applications

Vous constatez les applications disponibles directement sur le poste :
dans le menu Démarrer, et parfois sous forme de raccourcis. Il n'existe aucun
écran où vous géreriez vous-même la liste de vos applications : ce que le poste
affiche est la liste décidée pour lui.

::: attention
Vous ne pouvez pas installer une application vous-même sur ces postes, et
c'est voulu. Une application s'ajoute en la demandant à votre établissement
(voir plus bas), pas en la téléchargeant depuis Internet.
:::

## Comment une application arrive sur le poste

Le trajet est le même pour toutes les applications :

1. l'établissement choisit une application pour votre salle (ou pour tous les
   postes) ;
2. le serveur de l'établissement prépare cette liste et la tient à jour ;
3. votre poste va chercher cette liste **tout seul** et installe ce qui lui
   manque — c'est le rôle de l'[agent](/glossaire#agent), un petit logiciel
   présent sur chaque poste ;
4. l'application apparaît alors dans le menu Démarrer.

Ce travail ne vous demande aucune manipulation : le poste s'en occupe pendant
qu'il est allumé.

**Combien de temps cela prend.**

::: delai-effet agent
Le poste va chercher sa configuration peu après son démarrage, puis à nouveau
régulièrement pendant la journée. En général, une application ajoutée pour votre
salle apparaît dans l'heure qui suit sur un poste allumé.
:::

Éteindre et rallumer le poste — ou simplement le laisser un moment allumé — aide
à ce qu'il se mette à jour. Si l'application tarde vraiment, le référent
numérique de l'établissement a le moyen de demander à un poste de se mettre à
jour sans attendre.

## Une application me manque : que faire

1. **Vérifiez d'abord vous-même.** Cherchez l'application dans le menu Démarrer
   (le nom affiché peut différer légèrement de celui que vous avez en tête).
   Laissez au poste le temps de se mettre à jour ; un redémarrage du poste
   aide.
2. **Comparez avec les autres postes de la salle.** Si l'application est bien
   présente sur d'autres postes de la même salle mais pas sur le vôtre,
   signalez-le comme un problème propre à ce poste.
3. **Si elle n'est nulle part dans la salle, demandez-la.** Adressez-vous au
   référent numérique de l'établissement en indiquant le nom de l'application,
   la salle concernée, et si possible le nom du poste — il est en général
   inscrit sur une étiquette collée sur la machine, sans aucune manipulation à
   faire.

::: attention
Ajouter une application reste une décision de l'établissement : votre demande
sera examinée, mais elle n'ouvre pas un droit automatique à obtenir
l'application.
:::
