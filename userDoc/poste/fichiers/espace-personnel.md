# Où sont mes documents personnels ?

Cette fiche vous indique où enregistrer votre travail pour le retrouver, quel
que soit le poste sur lequel vous vous connectez.

## Votre dossier personnel

Chaque personne dispose d'un [espace personnel](/glossaire#espace-personnel) :
un dossier qui n'appartient qu'à vous. Il n'est pas rangé sur le poste
lui-même, mais sur le serveur de l'établissement. Le poste n'en garde donc
aucune copie une fois votre session fermée.

Dans l'explorateur de fichiers de Windows, il apparaît comme un lecteur nommé
**« Mes documents »**, repéré par la lettre **`K:`**. C'est là que vous
enregistrez tout ce que vous voulez conserver.

![Explorateur de fichiers Windows avec le lecteur « Mes documents » (K:) dans la liste des emplacements.](/captures/poste/fichiers/espace-personnel/explorateur-mes-documents.png)

## Le retrouver sur n'importe quel poste

Parce que votre espace personnel vit sur le serveur, ce que vous y enregistrez
sur un poste se retrouve **à l'identique** sur tous les autres postes de
l'établissement. Vous commencez un travail dans une salle, vous le terminez
dans une autre : le contenu de « Mes documents » vous suit. C'est la règle de
base à connaître pour ne jamais perdre son travail.

## Il n'appartient qu'à vous

Les autres élèves et enseignants n'ont pas accès à votre espace personnel :
depuis les postes, vous seul y accédez, grâce à votre compte. Ce que vous y
déposez n'est donc visible par personne d'autre autour de vous.

## Sa taille peut être limitée

Votre établissement peut fixer une limite à la place que votre espace personnel
occupe. Si cette limite est atteinte, l'enregistrement d'un nouveau fichier
échoue : il faut alors faire du ménage dans vos documents avant de pouvoir en
ajouter d'autres.

::: attention
**Selon les choix de votre établissement, cet espace peut ne pas exister sur
votre poste.** Si vous ne le voyez pas, ce n'est pas une panne : adressez-vous
à votre référent numérique.
:::

## À retenir

Pour retrouver votre travail où que vous soyez, enregistrez-le dans
**« Mes documents » (`K:`)**. C'est le seul endroit qui vous suit partout et
que vous êtes seul à consulter.
