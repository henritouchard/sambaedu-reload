# Comment changer mon mot de passe ?

Cette fiche explique comment changer vous-même votre mot de passe, sans
passer par le référent numérique (la personne qui gère l'informatique de
votre établissement).

## Contexte d'usage

Ce geste se fait directement depuis votre poste, pendant que votre session
est ouverte.

## Les gestes

1. Appuyez sur les touches Ctrl + Alt + Suppr.
2. Choisissez « Modifier un mot de passe ».
3. Saisissez votre mot de passe actuel, puis le nouveau mot de passe deux
   fois (la seconde fois pour le confirmer).
4. Validez.

::: delai-effet immediat
Le nouveau mot de passe vaut aussitôt sur tous les postes de l'établissement :
dès votre prochaine connexion, où que ce soit, c'est lui qu'il faut utiliser.
:::

## Résultat observable

Votre mot de passe est changé : vous pouvez fermer puis rouvrir votre
session avec le nouveau mot de passe.

::: attention
Si le nouveau mot de passe est refusé, choisissez-en un plus long. Et ne le
communiquez à personne, y compris au référent numérique : il n'en a jamais
besoin pour vous aider.
:::
