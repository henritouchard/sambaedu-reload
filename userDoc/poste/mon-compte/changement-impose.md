# Pourquoi on me demande de changer mon mot de passe ?

Cette fiche explique pourquoi cela arrive et ce qu'il faut faire quand cela
vous est demandé avant de pouvoir ouvrir votre session.

## Contexte d'usage

Ce n'est pas une erreur ni un signe de problème : cela arrive dans deux cas
précis.

- Votre compte vient d'être créé.
- Le référent numérique (la personne qui gère l'informatique de votre
  établissement) vous a remis un nouveau mot de passe, par exemple après un
  oubli.

Dans les deux cas, vous devez choisir un nouveau mot de passe avant de
pouvoir ouvrir votre session.

## Les gestes

### Sur votre poste (le cas le plus courant)

1. Au moment d'ouvrir votre session, le poste vous demande de choisir un
   nouveau mot de passe.
2. Saisissez le mot de passe qui vous a été remis, puis le nouveau que vous
   choisissez.
3. Validez : votre session s'ouvre avec le nouveau mot de passe.

### Si vous vous connectez sur le site de l'établissement, dans un navigateur (plus rare)

1. Après avoir saisi votre identifiant et votre mot de passe actuels, une
   page vous prévient qu'un changement est nécessaire.
2. Saisissez votre mot de passe actuel, puis le nouveau, deux fois (au moins
   8 caractères).
3. Validez avant la fin du quart d'heure affiché à l'écran — passé ce délai,
   il suffit de recommencer la connexion depuis le début.

::: delai-effet immediat
Le nouveau mot de passe vaut aussitôt sur tous les postes de l'établissement.
:::

## Résultat observable

Votre session s'ouvre avec le nouveau mot de passe ; vous pourrez l'utiliser
désormais sur n'importe quel poste de l'établissement. Si vous n'y parvenez pas,
le référent numérique de l'établissement peut réinitialiser votre mot de passe.
