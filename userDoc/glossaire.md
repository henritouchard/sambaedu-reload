# Glossaire

Les mots ci-dessous reviennent dans les fiches des deux parcours. Chacun est
défini une seule fois ici, en langage courant — les fiches y renvoient au
lieu de le réexpliquer à chaque page.

## Parc {#parc}

Un **parc** est un groupe nommé de postes informatiques de l'établissement.
C'est l'unité à laquelle on rattache des réglages et des applications : tous
les postes d'un même parc reçoivent les mêmes réglages et les mêmes
applications propres à ce parc, en plus de ce que tout le monde reçoit (voir
[socle commun](#socle-commun)).

## Groupe de postes {#groupe-de-postes}

Autre nom pour un [parc](#parc) : il s'agit du même objet.

## Socle commun {#socle-commun}

Le **socle commun** regroupe les applications installées sur TOUS les postes
de l'établissement par défaut, indépendamment du [parc](#parc) auquel un poste
appartient.

## Capacité {#capacite}

Une **capacité** est un réglage activable qu'un administrateur peut
appliquer sur les postes — par exemple un fond d'écran, une imprimante, un
lecteur réseau ou une règle de pare-feu. Une capacité peut s'appliquer à tout
l'établissement ou seulement à un [parc](#parc) donné.

## Profil applicatif {#profil-applicatif}

L'expression « profil applicatif » désigne deux choses distinctes selon le
contexte :

- un **ensemble d'applications** que l'administrateur assigne à un ou
  plusieurs [parcs](#parc) : tous les postes du parc reçoivent alors ces
  applications ;
- un **profil de navigateur ou de messagerie** (Firefox, Thunderbird) qui
  suit l'utilisateur d'un poste à l'autre, grâce à son
  [espace personnel](#espace-personnel) : marque-pages, extensions et
  réglages personnels retrouvés quel que soit le poste utilisé.

## Agent {#agent}

L'**agent** est un petit logiciel présent sur chaque poste. Il récupère la
configuration décidée sur le serveur et l'applique sur le poste — au
démarrage, à l'ouverture de session, puis régulièrement pendant que le poste
est allumé.

## Dépôt d'applications {#depot-applications}

Le **dépôt d'applications** est la source dans laquelle un administrateur
choisit les applications prêtes à être installées sur les postes.

## Espace personnel {#espace-personnel}

L'**espace personnel** est le dossier personnel d'un utilisateur. Il est
stocké sur le serveur de l'établissement et retrouvé automatiquement sur
n'importe quel poste sur lequel cet utilisateur ouvre une session.

## Partage {#partage}

Un **partage** est un dossier commun à un groupe de personnes (une classe,
une équipe), accessible depuis les postes concernés avec une lettre de
lecteur dédiée.
